# Página Pessoal — Tarefa de CSS

## Descrição do projeto

Este repositório contém o desenvolvimento de uma **página pessoal responsiva**, criada como parte da **Tarefa de CSS** do processo seletivo da INJunior. O projeto dá continuidade à tarefa anterior de HTML e tem como foco a aplicação prática dos principais conceitos de **CSS moderno**, seguindo o layout de referência disponibilizado no Figma.

Todo o projeto foi desenvolvido **exclusivamente com HTML e CSS**, respeitando as regras e recomendações propostas na atividade.

---

## Objetivos da atividade

- Estilizar a página individual criada na tarefa de HTML
- Aplicar conceitos fundamentais de CSS
- Seguir o layout de referência proposto no Figma
- Garantir responsividade para diferentes tamanhos de tela

---

## Requisitos atendidos

- Utilização apenas de **HTML e CSS**
- Layout baseado no design disponibilizado no Figma
- Página totalmente **responsiva** (desktop e mobile)
- Estrutura semântica com boas práticas de HTML
- Paleta de cores e tipografia definidas de forma consistente

---

## Desafios implementados

- **Menu hambúrguer funcional** utilizando apenas HTML e CSS
- **Animações com :hover** aplicadas em diferentes elementos da página
- Transições suaves para melhorar a experiência do usuário

---

## Estrutura da página

- Header com navegação e menu hambúrguer para mobile
- Seção de apresentação pessoal
- Listas com hobbies e ranking pessoal
- Cards estilizados e responsivos
- Formulário de feedback
- Footer com links externos

---

## Tecnologias utilizadas

- HTML5
- CSS3

---

## Organização do projeto

- index.html: estrutura principal da página
- style.css: estilização completa e responsividade
- assets/: imagens e recursos visuais utilizados no projeto

---

## Observações finais

Foi desenvolvido com foco no aprendizado e na prática de CSS, incluindo responsividade, animações e organização visual. Todas as decisões de layout e estilo buscaram equilíbrio entre fidelidade ao design de referência e clareza no código.
